# 汉字幸存者 🈶📱（幼儿园识字版）

幸存者类识字游戏：小朋友操控小金豆躲避小怪兽，**升级时听语音选汉字**，
**技能卡出现时必须大声喊出卡片上的汉字**（语音识别）才能升级——只认声音，不认手指！

## 玩法（给家长看）

| 环节 | 玩法 | 学什么 |
|---|---|---|
| 🕹 移动 | 手机按住拖动 / 电脑 WASD·方向键，Shift 冲刺 | 武器自动攻击，孩子专注走位 |
| 🔊 听音选字 | 升级时语音读"哪个是大字？大象的大。"，从 4 个大字里点出正确的 | 音→形 对应 |
| 🎤 喊字升级 | 技能卡是一个大字（大/水/山/木/金…），**大声喊出来**才升级 | 形→音 输出，加深记忆 |
| 🛡 Boss 识字护盾 | 语音读字，跑到正确的字气泡上撞碎护盾 | 听觉辨识 + 反应 |

- 技能与汉字含义同构：**水**=回血、**山**=护盾、**风**=加速、**金**=吸经验、**月**=环刃、**电**=闪电链、**炸**=榴弹、**冰**=减速……玩技能 = 体验字义
- 课程 60 个学前基础字，随等级逐步解锁（开局 6 个字，从 0 开始）
- 答错的字进错字本，游戏中间隔重现；家长设置里可导出学字档案
- 8 分钟生存胜利，之后进入无尽模式

## 运行

```bash
cd 汉字幸存者
npm install
npm run dev      # 手机电脑同一 WiFi，扫控制台地址即可真机试玩
npm run build    # 产出 dist/，任意静态服务器可部署
```

## 语音要求（重要）

- **语音朗读**（出题）：所有现代浏览器可用（Web Speech TTS）
- **喊字识别**（选卡）：需要 `webkitSpeechRecognition` —— **推荐 Chrome / Edge**；
  首次使用允许麦克风权限；识别走浏览器厂商服务（需联网，本地不保存录音）
- 不支持语音识别的浏览器（如 Firefox）：选卡界面会提示，并临时开放 1/2/3 数字键作为家长辅助通道（正常环境无任何触摸/键盘选卡）
- 孩子喊字识别不灵时：靠近麦克风、大声、慢一点、只说一个字

## 目录结构

```
src/
  data/chars.js      # 60 字课程库（拼音/例词/emoji/字形提示）+ 出题器
  data/skills.js     # 8 主技能字卡（大小水山风火日地）+ 6 被动字卡（木金田石星足）+ 心
  data/weapons.js    # 10 武器字卡（月电炸光箭花蛇回冰雷）
  systems/voice.js   # TTS 朗读 + 语音识别 + 喊字匹配（多候选容错）
  systems/quiz.js    # 听音选字浮层（答错语音教学、揭晓拼音）
  systems/profile.js # 学字档案：每字统计/错字本/自适应出题
  scenes/GameScene.js  # 战斗主场景（继承数学幸存者全量防卡死修复）
  scenes/UIScene.js    # HUD + 喊字选卡界面（语音循环聆听）
```

基于《数学幸存者》引擎（福建省中职概率统计版）改造，战斗/升级/防卡死逻辑经过 30 分钟自动化耐久验证。
